# Памятка для защиты

## Что показать преподавателю

1. Запустить `./mvnw spring-boot:run` и показать SQL `CREATE TABLE tasks` в логах.
2. Создать минимум пять разных задач через `POST /tasks`.
3. Открыть H2 Console (`/h2-console`, JDBC URL `jdbc:h2:mem:taskdb`) и выполнить `SELECT * FROM TASKS;`.
4. Показать страницы `/tasks?page=0&size=3&sort=id` и `/tasks?page=1&size=3&sort=id`.
5. Показать фильтры `status`, `priority` и их комбинацию.
6. Выполнить `/tasks/search?keyword=...` и `/tasks/stats`.
7. Выполнить PUT и DELETE, проверить изменения в H2.
8. Показать SQL Hibernate для SELECT, INSERT, UPDATE и DELETE.

## Что нужно уметь объяснить

1. **Почему переход с in-memory repository на JPA почти не затрагивает Controller?** Контроллер зависит от сервиса, а сервис — от интерфейса репозитория. Детали хранения скрыты за этими слоями.
2. **Что такое dependency injection?** Объект получает готовые зависимости извне. Spring создаёт bean реализации `TaskRepository` и передаёт его в конструктор сервиса.
3. **Зачем JPA конструктор без аргументов?** Hibernate использует его для создания entity при чтении строки из БД.
4. **Зачем `@Entity`?** Аннотация включает класс в JPA-модель и позволяет Hibernate сохранять его экземпляры.
5. **Что делает `@Id`?** Обозначает первичный ключ entity.
6. **Что делает `@GeneratedValue`?** Передаёт генерацию ID базе данных; `IDENTITY` использует identity-столбец.
7. **Почему `EnumType.STRING` лучше `ORDINAL`?** В БД сохраняется понятное имя enum. Перестановка констант не испортит старые данные, в отличие от числовых ordinal.
8. **Что такое `JpaRepository`?** Интерфейс Spring Data с готовыми CRUD-операциями, пагинацией и сортировкой. Реализацию генерирует Spring.
9. **Что такое derived query?** Запрос, который Spring Data строит из имени метода, например `findByStatusAndPriority`.
10. **Как Spring понимает `findByStatusAndPriority`?** Разбирает `findBy`, свойства entity `Status` и `Priority`, а `And` превращает в логическое условие SQL.
11. **Чем JPQL отличается от SQL?** JPQL обращается к entity и их Java-полям, а SQL — к таблицам и колонкам конкретной БД.
12. **Почему в JPQL `FROM Task`, а не `FROM tasks`?** `Task` — имя entity, а `tasks` — имя таблицы, используемое SQL.
13. **Что делает `@Query`?** Явно связывает метод репозитория с JPQL-запросом, когда имени метода недостаточно или нужен агрегат.
14. **Что такое `Pageable`?** Описание номера страницы, размера и сортировки, которое Spring Data переводит в запрос к БД.
15. **Что такое `Page<Task>`?** Контент одной страницы плюс метаданные: общее число записей и страниц, текущая страница и размер.
16. **Чем `Page` отличается от `List`?** `List` содержит только элементы, а `Page` также содержит метаданные и обычно выполняет дополнительный count-запрос.
17. **Что такое `page` и `size`?** `page` — номер страницы с нуля, `size` — максимальное количество записей на странице.
18. **Что делает `Sort`?** Добавляет сортировку (`ORDER BY`) на уровне БД.
19. **Что означает `ddl-auto=create-drop`?** Hibernate создаёт схему при старте и удаляет при закрытии контекста.
20. **Почему `create-drop` нельзя использовать в production?** При остановке приложения схема и данные удаляются; автоматическое изменение схемы также плохо контролируется.
21. **Для чего `show-sql=true`?** Печатает SQL Hibernate в лог, что удобно для обучения и диагностики.
22. **Почему в production применяют Flyway/Liquibase?** Они хранят версионированную, повторяемую историю миграций и позволяют контролируемо обновлять схему между релизами.
